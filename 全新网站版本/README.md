## UI 组件详解

### 1. 标题区域

- **元素**：`<h1>` 标签
- **样式**：黄色文字（`#FFD700`），Minecraft 字体，带阴影效果
- **内容**：`FUNCTION 图片粒子生成工具`

### 2. 按钮控制区域

包含三个并排显示的按钮/提示元素：

| 元素 | ID | 类型 | 说明 |
|------|-----|------|------|
| 方向切换 | `directionButton` | button | 初始文本为"切换为XZ模式"，点击后在 XY/XZ 模式间切换 |
| 生成下载 | `generateButton` | button | 初始状态为禁用，选择图片后变为可用 |
| 文件计数 | `fileCountHint` | span | 显示预估生成的文件数量，初始为"0 文件" |

### 3. 文件选择区域

- **可见按钮**：`browseButton`，显示"选择图片"
- **隐藏输入**：`imageInput`，`type="file"`，`accept="image/*"`，通过按钮点击触发

### 4. 参数设置区域

包含三个输入组：

#### 4.1 图片尺寸
- **标签**："图片尺寸（正方形像素）："
- **输入框**：`sizeInput`，类型为 number，默认值 100，范围 10-500

#### 4.2 粒子密度
- **标签**："粒子密度："
- **输入框**：`densityInput`，类型为 number，默认值 5，范围 1-20，步长 0.1
- **提示**："数值越小越密集"

#### 4.3 坐标偏移
- **标签**："坐标偏移（X Y Z）："
- **输入框**：`coordinates`，类型为 text，默认提示"例如：10 5 3"
- **格式说明**："输入格式：X Y Z（用空格分隔三个数字）"
- **错误提示**：`coordinatesError`，验证失败时显示红色错误信息

### 5. 预览画布区域

- **容器**：`canvas-container`，flex 布局居中
- **画布**：`previewCanvas`，固定宽高 500x500，白色背景
- **响应式**：窗口大小变化时自动调整画布尺寸，保持正方形比例

### 6. 提示文字区域

- **元素**：`.note` 类
- **内容**："温馨提示：图片将被调整为正方形，颜色、细节和亮度等保持不变"

### 7. 返回按钮区域

- **链接**：指向 `../index.html`
- **按钮**：`menu-btn` 样式，显示"返回首页"

## 交互逻辑说明

### 图片选择流程

1. 用户点击"选择图片"按钮
2. 触发隐藏的 `fileInput` 文件选择对话框
3. 用户选择图片文件后，触发 `change` 事件
4. 通过 `FileReader` 读取图片并显示预览

### 参数调整流程

1. 用户修改"图片尺寸"输入框
2. 实时重新渲染预览画布，保持图片比例
3. 用户修改"粒子密度"输入框
4. 实时更新文件计数显示

### 模式切换流程

1. 用户点击"切换方向"按钮
2. 切换 `isXZMode` 状态（false=XY模式，true=XZ模式）
3. 更新按钮文本（"切换为XY模式" / "切换为XZ模式"）
4. 重新渲染预览

### 生成流程

1. 用户点击"生成指令下载"按钮
2. 按钮变为禁用状态，显示"正在生成..."
3. 根据当前设置生成粒子指令
4. 将指令按每文件10000条拆分
5. 使用 JSZip 打包为 zip 文件下载
6. 恢复按钮状态

## 视觉设计特点

- **深色主题**：背景使用深蓝到紫色的渐变，卡片为深灰色
- **Minecraft 风格**：标题使用 Minecraft 字体，按钮采用像素风格设计
- **绿色按钮**：主按钮使用绿色渐变（`#4CAF50` → `#388E3C`），带阴影效果
- **响应式布局**：移动端自动调整卡片宽度和按钮排列方式
